Browser downloads

Grabify pauses the browser transfer immediately and takes over HTTP and HTTPS files. The browser resumes automatically if the desktop app cannot accept the handoff.

Torrent links

When you click a magnet link, Grabify takes it instead of the browser's default torrent app. Turn this off to let the browser handle magnet links.

Video detection

Enabling this requests access to observe media on websites. For authenticated file downloads, matching browser cookies are handed only to the local Grabify app for that transfer and are never saved to its database.

Disabled sites

DRM-protected media is never offered or downloaded.
